# 07 - Init Prompt

## Prompt

Crea `INIT_PROMPT.md`: un prompt iniziale riusabile per avviare Codex App su questo repository durante un hands-on.

Il prompt deve dire a Codex:

- quali file leggere all'inizio;
- come interpretare il progetto;
- quali vincoli rispettare;
- come distinguere core app, observability e GenAI;
- come evitare fake data;
- come validare modifiche backend;
- come validare modifiche frontend;
- da quale feature partire;
- come scrivere il final answer.

Non modificare codice.

## Expected Output

Un `INIT_PROMPT.md` pronto da incollare in Codex App per avviare una sessione guidata.

## Validation

- Il prompt deve essere autosufficiente.
- Deve riferirsi a file reali del repository.
