# 03 - Frontend Documentation

## Prompt

Crea `docs/FRONTEND.md` documentando il frontend AngularJS servito dall'API Gateway.

Mappa:

- struttura dei file statici;
- moduli AngularJS;
- route UI;
- controller;
- template;
- chiamate API;
- chatbox GenAI;
- asset e CSS;
- eventuale processo di build CSS.

Non modernizzare il frontend e non proporre una riscrittura React.
Descrivi fedelmente l'architettura attuale.

## Expected Output

Un documento `docs/FRONTEND.md` che permetta a Codex o a uno sviluppatore di modificare il frontend legacy senza dover riscoprire la struttura ogni volta.

## Validation

- Verifica che ogni controller/template citato esista.
- Riporta il mapping tra UI e API in forma tabellare.
