# 01 - Repo Briefing

## Prompt

Analizza questo repository Spring Petclinic Microservices e crea `docs/HANDSON.md`.

Il documento deve spiegare in modo operativo:

- scopo del progetto;
- servizi presenti;
- porte esposte;
- dipendenze principali;
- cosa e' core e cosa e' opzionale;
- differenza tra avvio locale senza Docker e avvio con Docker Compose.

Non modificare codice.
Usa solo evidenza dal `README.md`, dai `pom.xml`, da `docker-compose.yml` e dalla struttura del repository.

## Expected Output

Un documento `docs/HANDSON.md` leggibile da chi deve usare il repository durante un hands-on Codex App.

## Validation

- Verifica che il documento non contenga assunzioni non supportate dal repository.
- Riporta nel final answer i file letti e il file creato.
