# 06 - Backlog Hands-On

## Prompt

Crea `BACKLOG.md` con una lista ordinata di feature adatte a un hands-on Codex App.

Per ogni feature indica:

- obiettivo;
- perche' e' utile didatticamente;
- file probabili;
- backend coinvolto;
- frontend coinvolto;
- test attesi;
- criterio di completamento;
- livello di difficolta';
- rischi o prerequisiti.

Ordina dal task piu' didattico e sicuro al piu' avanzato.

Non implementare le feature.

## Expected Output

Un backlog riusabile per guidare una sessione hands-on progressiva.

## Validation

- Ogni feature deve essere ancorata a codice realmente presente nel repo.
- Evita task generici non verificabili.
