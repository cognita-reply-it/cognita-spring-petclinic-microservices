# 04 - Runbook Operativo

## Prompt

Crea `docs/RUNBOOK.md` con istruzioni pratiche per avviare e verificare il progetto.

Copri:

- prerequisiti locali;
- avvio senza Docker;
- ordine corretto dei servizi;
- avvio con Docker Compose;
- URL da controllare manualmente;
- GenAI con API key;
- Grafana, Prometheus e Zipkin come componenti opzionali;
- troubleshooting comune;
- comandi Maven utili;
- quando usare Docker e quando non serve.

Non modificare codice o script.

## Expected Output

Un runbook operativo, asciutto e verificabile, adatto a un hands-on.

## Validation

- Non promettere che un comando e' stato eseguito se non lo hai eseguito.
- Se non avvii il progetto, specifica che il documento e' stato validato tramite lettura del repository.
