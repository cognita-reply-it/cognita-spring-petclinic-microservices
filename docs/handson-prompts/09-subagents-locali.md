# 09 - Subagents Locali

## Prompt

Rendi il repository pronto per lavoro con subagents locali.

Crea una configurazione minima sotto `.codex/agents/` per questi ruoli:

- documentation engineer;
- Java/Spring backend engineer;
- legacy AngularJS frontend engineer;
- QA/test engineer.

Aggiorna `AGENTS.md` spiegando quando usarli.
Mantieni il setup piccolo e pratico.

Non creare piu' agenti del necessario e non introdurre workflow esterni non richiesti.

## Expected Output

Una piccola configurazione `.codex/agents/` e un aggiornamento del contratto locale.

## Validation

- Verifica che i file creati siano leggibili e coerenti.
- Riporta nel final answer quali agenti sono stati aggiunti e per quali task vanno usati.
